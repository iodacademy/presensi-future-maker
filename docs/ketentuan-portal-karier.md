# Ketentuan Portal Karier Future Makers

Portal Karier mempertemukan peserta magang dengan lowongan dari mitra. Lowongan terbagi dua skema, yaitu Full Internship dan Project Based. Skema peserta ditentukan dashboard nilai. Ketentuan di bawah berlaku untuk peserta, PIC mitra, dan admin.

## 1. Ketentuan Umum

### 1.1 Akses menu Karier

Menu Karier hanya terbuka bagi peserta berstatus Full Internship atau Project Based. Peserta berstatus Tidak Ditempatkan dan Menunggu tidak dapat membuka menu Karier.

### 1.2 Pembukaan pendaftaran

Admin membuka dan menutup pendaftaran. Selama pendaftaran ditutup, peserta hanya dapat melihat daftar lowongan.

### 1.3 Pengiriman lamaran

Satu lowongan hanya dapat dilamar satu kali. Lamaran yang sudah terkirim tidak dapat diubah.

### 1.4 Berkas CV

CV wajib berformat PDF dengan ukuran maksimal 2 MB. Setiap peserta dapat menyimpan paling banyak lima CV.

### 1.5 Lamaran yang tidak lolos

Lamaran yang dinyatakan tidak lolos langsung mengembalikan jatah kuota. Peserta dapat segera melamar lowongan lain.

## 2. Tingkatan Peserta

Setiap peserta magang masuk satu *tier* berdasarkan SPA di dashboard nilai.

| *Tier* | SPA | Kuota Full Internship | Kuota Project Based | Batas uang saku Full Internship | Batas uang saku Project Based |
|---|---|---|---|---|---|
| A | 85 ke atas | 5 lamaran berjalan | 3 jatah proyek | Rp1.000.000 per bulan | [BUTUH DATA: batas per proyek *tier* A] |
| B | 75 – 84 | 3 lamaran berjalan | 2 jatah proyek | Rp900.000 per bulan | [BUTUH DATA: batas per proyek *tier* B] |
| C | di bawah 75 | 2 lamaran berjalan | 1 jatah proyek | Rp800.000 per bulan | [BUTUH DATA: batas per proyek *tier* C] |

Peserta hanya dapat melamar lowongan yang uang sakunya tidak melebihi batas *tier*-nya. Lowongan yang melebihi batas tidak tampil sebagai lowongan yang dapat dilamar.

Batas uang saku Project Based ditetapkan setelah lowongan Project Based pertama masuk dan kisaran nilainya terlihat.

## 3. Perbedaan Full Internship dan Project Based

| Aspek | Full Internship | Project Based |
|---|---|---|
| Lowongan yang dapat dilamar | Full Internship dan Project Based | Project Based |
| Isi kuota | Lamaran yang sedang diproses | Lamaran yang sedang diproses dan proyek yang sedang dikerjakan |
| Jatah kembali | Saat lamaran tidak lolos | Saat lamaran tidak lolos atau proyek ditandai selesai |
| Jumlah penempatan | Satu tempat | Beberapa proyek sekaligus, sebanyak kuota *tier* |
| Satuan uang saku | Per bulan | Per proyek, untuk seluruh durasi proyek |
| Penanda selesai | Tidak ada | Admin atau PIC menandai proyek selesai |

### 3.1 Satu peserta, satu penempatan untuk Full Internship

Peserta yang menerima tawaran Full Internship hanya mendapat satu penempatan. Begitu tawaran diterima, seluruh lamaran lain dan jadwal wawancaranya otomatis dibatalkan, termasuk lamaran Project Based. Peserta tersebut tidak dapat melamar lagi.

### 3.2 Jatah proyek untuk Project Based

Peserta Project Based dapat mengerjakan beberapa proyek sekaligus selama jatahnya masih ada. Lamaran lain tetap berjalan ketika satu proyek diterima. Jatah baru kembali setelah admin atau PIC menandai proyek selesai.

Contoh peserta Project Based *tier* A dengan kuota tiga:

| Keadaan | Jatah yang tersedia |
|---|---|
| Tiga lamaran terkirim dan ketiganya lolos | 0 |
| Satu dari tiga proyek selesai | 1 |
| Ketiga proyek belum selesai | 0 |
| Dua dari tiga lamaran tidak lolos | 2, langsung dapat dipakai |

### 3.3 Uang saku Project Based

Uang saku Project Based tercantum utuh per proyek dan tidak dibagi per bulan. Formulir lowongan Project Based memuat durasi proyek dalam bulan sebagai informasi bagi peserta. Proyek berdurasi dua bulan dengan uang saku Rp1.600.000 berarti Rp1.600.000 untuk seluruh dua bulan itu.

## 4. Peserta Full Internship yang Diterima di Project Based

Peserta Full Internship dapat melamar lowongan Project Based. Begitu peserta menerima tawaran Project Based, jalurnya berubah menjadi Project Based secara permanen:

1. Peserta tidak dapat lagi melamar lowongan Full Internship.
2. Lamaran Full Internship yang masih berjalan otomatis ditutup.
3. Kuota peserta mengikuti kuota Project Based sesuai *tier*-nya.
4. Proyek yang baru diterima langsung memakai satu jatah.
