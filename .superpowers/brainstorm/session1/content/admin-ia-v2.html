Konten menu aktif tampil di sini →
1. Jadwal & Presensi (gabung)
Buat jadwal kelas per Kota+Kelas → otomatis jadi sesi presensi dengan QR. Tidak ada langkah terpisah untuk "aktifkan presensi" — begitu jadwal dibuat, slot presensinya sudah ada.
FLOW
Pilih Kota+Kelas→Tambah pertemuan: tanggal, jam, Online/Offline, materi→Simpan → sesi otomatis muncul di list dengan tombol QR→Saat waktunya: Online auto-buka 19:00 / Offline tap Buka→QR tampil, monitor hadir live→Auto/manual tutup→Ekspor rekap presensi (CSV) di halaman ini
2. Mentoring
Generate slot massal, Fase Bootcamp/Magang, monitor booking, quota 2x/siswa.
FLOW
Pilih Kota+Kelas (mentor auto)→Pilih Fase→Isi tanggal+jam+durasi → generate slot→Publish→Siswa booking → Calendar+Meet auto→Ekspor rekap booking (CSV) di halaman ini
3. Tugas
Upload Brief, lihat submission Harian & Capstone, beri nilai+feedback.
FLOW
Buat tugas + upload Brief PDF + deadline→Siswa kumpul (link Drive)→Admin nilai + feedback→Simpan→Ekspor rekap tugas+nilai (CSV) di halaman ini
4. Peserta & Mentor
Kelola daftar peserta per Kota+Kelas, mentor ter-assign, progres individu.
FLOW
Pilih Kota+Kelas→Lihat list peserta + mentor→Klik peserta → progres individu (presensi %, tugas, mentoring)→Tambah/hapus peserta
