Admin — Semua Tugas (Lengkap)

Ringkasan 8 tugas utama admin di desktop. Semua pakai warna & ikon yang sama, tanpa emoji.

1. Kelola Jadwal Kelas Bootcamp
Buat/edit jadwal kelas per Kota+Kelas (mis. Web Programming Semarang ≠ Surabaya). Jadwal sama untuk semua mentor di kelas itu. Publish → peserta lihat di tab Jadwal.
Kota: Jakarta/Semarang/Surabaya • Kelas: Web Programming/Data Analyst/Digital Marketing
2. Kelola Slot Mentoring
Pilih Kota+Kelas → mentor auto 1 orang → pilih Fase Bootcamp / Magang → isi tanggal 1-30 Sep + jam + durasi 45m → generate 40 slot → cek bentrok → Publish. Peserta book rebutan (jatah 2x).
3. Buka QR Presensi
Online 19:00-22:00 auto buka/tutup (QR muncul di admin). Offline tap Buka manual. QR refresh 30s, tampil di layar/projector, counter hadir live (12/20).
4. Monitor Presensi
Lihat siapa hadir/tidak per sesi & per peserta, persentase kehadiran, riwayat scan. Data simpan di Firestore.
5. Upload Brief Tugas
Upload file Brief per tugas (PDF) → jadi tombol "Unduh Brief Tugas Berikut: Download" di app peserta. Bisa ganti file kapan saja.
6. Nilai Tugas Harian
Buka link Drive peserta, beri nilai 0-100 + feedback teks. Status berubah Terkumpul → Dinilai. Peserta lihat feedback di kartunya.
7. Nilai Capstone
Sama seperti Harian, tapi hanya kebuka kalau semua Harian sudah terkumpul. Beri nilai + feedback final. Jadi penentu kelulusan.
8. Ekspor Data
Ekspor presensi (Firestore) + tugas (link Drive + nilai) per Kota+Kelas ke CSV untuk laporan Plan Indonesia. Satu klik.

Tambahan yang implisit:

  • Kelola Peserta & Mentor assignment (1 mentor per Kota+Kelas sudah di-assign, mis. Rama → WP Semarang 9/10 orang)
  • Atur jadwal kelas bootcamp per Kota+Kelas (jadwal sama untuk semua mentor di kelas itu, beda antar kota/kelas)
  • Google Calendar + Meet: admin tidak input manual — sistem pakai akun penyelenggara sebagai organizer, auto invite peserta & mentor
