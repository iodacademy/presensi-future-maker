Cara Tambah Peserta per Mentor — 3 Opsi

Pilih salah satu cara kerja untuk menugaskan 19 peserta ke 2 mentor.

1. Import semua dulu
Import CSV: 19 nama masuk jadi 1 pool
2. Baru dibagi ke kolom mentor
Rama
Budi, Sinta...
Ilham
Dewi, Fajar...

A — Import dulu, baru bagi (yang tadi)

Upload 1 file CSV isi semua 19 nama sekaligus → sistem taruh di "pool belum di-assign" → admin drag/auto-bagi ke kolom Rama & Ilham.

Mentor Rama
Budi, Sinta...
+ Tambah untuk Rama
Mentor Ilham
Dewi, Fajar...
+ Tambah untuk Ilham

B — Import/tambah langsung per kolom mentor

Tiap kolom mentor punya tombol "+ Tambah" & "Import CSV" sendiri-sendiri. Admin upload/ketik nama langsung ke kolom Rama, lalu terpisah ke kolom Ilham. Tidak ada pool netral.

1 File CSV, ada kolom "Mentor"
nama, email, mentor
Budi, budi@..., Rama
Dewi, dewi@..., Ilham
Sinta, sinta@..., Rama
Upload → langsung ke-assign otomatis

C — Satu file CSV, kolom "Mentor" sudah ditentukan

Admin siapkan 1 file Excel/CSV yang sudah ada kolom Mentor (diisi manual di Excel dulu). Upload sekali, sistem langsung taruh tiap peserta ke mentor sesuai kolom itu. Tidak ada drag-drop di app.

💭 Rekomendasi saya: Opsi C — paling cepat untuk 40+ peserta di banyak kelas (tidak perlu drag manual satu-satu di app), admin cukup siapkan spreadsheet sekali. Tapi kalau kamu mau kontrol visual & gampang koreksi di app, Opsi A (yang tadi) juga oke.
